# Jev Second Brain

Local-first Markdown indexing, source-linked search, and reviewable relationship
suggestions. Jev is an optional BYOK judge for bounded note comparisons. The
source vault stays authoritative.

This repository is an MVP under development. See [MVP phases](docs/MVP.md) for
the intended command surface and delivery checks. Example vaults and tests use
synthetic notes only.

MIT licensed. Inference availability, data handling, and prices depend on the
configured provider; a code license does not make model calls free.
